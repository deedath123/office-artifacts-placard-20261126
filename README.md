## Entry

> Stapler, steel, c. 1997. The Accounts tribe bound treaties with a single rite; donor Gary still insists the jam of March 3rd was sabotage, not user error. Cat. No. 0417.

169 characters. A dry-witted curator's placard: the stapler recast as the ritual binding tool of the Accounts tribe, with a catalogue number, a date, a material, and a donor who still disputes the official record.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

Standard library only. Writes the single-line placard to `/output/entry.txt`.
